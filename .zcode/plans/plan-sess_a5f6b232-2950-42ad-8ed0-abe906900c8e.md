## 方法（沿用既有流程）

每簇：字面转录 C++ → `/tmp` 探针（`g++ -O2 -I /home/keith/projects/hifiasm xxx_probe.cpp $(ls /home/keith/projects/hifiasm/*.o | grep -v '/main.o$') -lz -lpthread`）生成黄金值 → Rust 回放单测（`--ignored`，关键黄金内嵌常驻）→ 接线 → 门禁（`scripts/compare_outputs.sh` + `cmp` 逐字节 + 日志锚点）→ 更新 docs/consistency.md → commit（per-feature 风格）。
